# Public project status

Riltra `0.1.0` is a pre-release, local-first CLI and MCP server. The [README](../README.md)
is the current reference for supported languages, evidence labels and known
limitations. Install and release checks are described in the [release guide](../release/README.md).

Published materials make no general performance, accuracy or product-comparison
claim. Results from a particular fixture or environment should not be read as a
claim about other repositories or platforms.
