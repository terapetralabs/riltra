# Public project status

Riltra `0.1.0` is a published pre-release, local-first CLI and MCP server.
The [README](../README.md) covers installation and agent setup. The
[capabilities guide](guide/capabilities.md) lists supported languages, evidence
labels, provider boundaries, and known limitations. Archive installation and
release checks are documented in the [release guide](../release/README.md).

Published materials make no general performance, accuracy or product-comparison
claim. Results from a particular fixture or environment should not be read as a
claim about other repositories or platforms.
